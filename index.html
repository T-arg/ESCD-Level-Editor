How links work

Drag a door dot onto another room’s door to connect them. Open-door lines are yellow. Closed-door lines are in red. A link into the exit room is purple; that approach door stays closed, the exit room door stays open. Only one purple connection is allowed — drawing another disconnects the first, so the next-level room has exactly one door. Cyan T = teleport, orange S = switch — drag onto the target room. Click a connected yellow/purple door, T, or S to drop the link and its data.

Floor influence

Switch OFF only. Tick which of the target room’s five floor slots toggle. Mask is the lower 5 bits: bit4 = floor 1 … bit0 = floor 5. Upper bits are not used.

C export

Rooms are 0-based. Max 32 rooms. Map positions snap to the 20px grid and are stored in a // LAYOUT comment so import restores the same layout without compiling into the game.

Room

Drag a palette sprite onto a tile. It snaps to the game’s tile center. Click a placed sprite to remove it. One thing per tile. Room 0 tile 12 is the droid start.
